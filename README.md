# Discord Siyah Klon 🖤

Discord'a benzeyen, **siyah temalı**, tamamen çalışan bir web chat uygulaması.

Pure **HTML + CSS + JavaScript** ile yapıldı. Backend yok, her şey tarayıcıda (localStorage) çalışıyor.

## Özellikler

- 🌙 Discord tarzı koyu (siyah) tema
- 🖥️ Sunucu listesi (sol sidebar)
- 📢 Metin kanalları + ses kanalları (görsel)
- 💬 Gerçek zamanlı mesaj gönderme (Enter ile)
- 💾 Mesajlar localStorage'da saklanır (sayfa yenilense bile kalır)
- 👥 Üye listesi (çevrimiçi / çevrimdışı)
- ⚙️ Kullanıcı ayarları (isim + avatar değiştir)
- ➕ Yeni sunucu oluşturma
- 📱 Temel responsive destek

## Nasıl Çalıştırılır?

1. Bu repoyu klonla veya dosyaları indir
2. `index.html` dosyasını tarayıcıda aç
3. Veya GitHub Pages ile yayınla

```bash
git clone https://github.com/MDCforLEGAL/discord-siyah-klon.git
cd discord-siyah-klon
# index.html'i aç
```

## GitHub Pages

Repo ayarlarından **Settings → Pages → Source: Deploy from a branch → main** seçerek canlı siteye alabilirsin.

## Not

Bu bir **frontend klon**. Gerçek Discord gibi:
- Gerçek zamanlı çoklu kullanıcı (WebSocket)
- Sesli / görüntülü arama
- Hesap sistemi
- Sunucu rollerı

yoktur. Eğitim ve demo amaçlıdır.
